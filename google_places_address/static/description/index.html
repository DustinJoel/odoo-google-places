Configuration Guide

Step 1: Google Cloud Platform

  1. Visit Google Cloud Console
  2. Create a new project or select an existing one
  3. Enable "Places API (New)" and "Maps JavaScript API"
  4. Create an API key with HTTP referrer restrictions
  5. Enable billing on your Google Cloud account

Step 2: Odoo Setup

  1. Install this module from Apps menu
  2. Go to Settings → General Settings
  3. Scroll to "Google Places API Integration"
  4. Enable the feature and paste your API key
  5. Configure optional country restriction and usage limits
  6. Save settings

Step 3: Start Using

  1. Open any Contact/Customer form
  2. Look for the "🌍 Search Address (Google Places)" field
  3. Start typing to see autocomplete suggestions
  4. Select an address and watch the magic happen!
