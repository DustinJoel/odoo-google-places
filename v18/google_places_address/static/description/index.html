Google Places Address Autocomplete

Intelligent Address Entry with Google Places API

Transform your contact management with intelligent address autocomplete powered by Google Places API. Save time, reduce errors, and improve data quality with real-time address suggestions.

Key Features

Real-Time Autocomplete

Start typing and see instant address suggestions from Google Places API. Select any address and watch all fields populate automatically.

Multi-Company Support

Perfect for multi-company setups. Each company can have its own API key, country restrictions, and usage limits.

Secure & Private

API key is securely stored server-side and never exposed to the browser. Company-specific access control ensures data security.

Cost Optimized

Smart API usage with field restrictions, country filters, and optional usage limits to control Google API costs.

How It Works

  1. Configure: Enter your Google Places API key in Settings → General Settings
  2. Search: Open any partner form and start typing in the Google Places search field
  3. Select: Choose an address from the dropdown suggestions
  4. Done: All address fields are automatically populated with accurate data
